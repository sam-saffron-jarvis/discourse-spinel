# Unintegrated parallel work

These trees/patches preserve separate development lanes. They are deliberately not presented as one integrated passing build.

- `serialization/fidelity/`: original-input inventory, source locks and original response/serialization bridge projections. The source bridge does not have a native execution pass.
- `serialization/roundhouse.patch`: narrow format-dispatch preservation and executed reduced CRuby/native regression; base/head are in the main snapshot manifest.
- `html-oracle/fidelity/`: original Rails TracePoint harness, real asset staging/provenance, thread-aware effect attribution and the parent-authored disposable PostgreSQL oracle harness. Actual runtime captures, authorization files, raw database/data files and logs are excluded.

The two native helper sessions were stopped/cancelled; their preserved source is included here, not a claim they remain running. The independent main source-fidelity worker continued during publication.
